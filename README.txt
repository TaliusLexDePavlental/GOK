САЙТ-КНИГА «ПОКА МЫ ВЫБИРАЕМ ДРУГ ДРУГА»

Файлы:
- index.html — сайт
- assets/ — иллюстрации, вырезанные из предоставленной визуальной сетки

Локальный запуск:
Откройте index.html в современном браузере. Интернет не нужен.

Публикация:
Загрузите index.html и папку assets целиком на статический хостинг (например, GitHub Pages). Не загружайте один index.html без папки assets, иначе иллюстрации не отобразятся.

Управление в чтении:
- «Содержание» открывает оглавление; на телефоне оно появляется выдвижной панелью.
- A− / A+ меняет размер шрифта.
- ◐ циклически переключает три темы: «Бумага», «Ночь» и «Рассвет»; название текущей темы появляется на экране.
- Тонкая полоса сверху показывает прогресс чтения.
