ПРОФИ | Погода и безопасность
================================

Содержимое:
- index.html — адаптивный сайт, который запрашивает прогноз Open-Meteo прямо в браузере.
- QR-код создаётся после публикации, когда будет известен постоянный адрес сайта.

Как опубликовать бесплатно на GitHub Pages:
1. Войдите в GitHub и создайте публичный репозиторий, например profi-weather.
2. Загрузите index.html в корень репозитория.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, branch main, folder /(root), затем Save.
5. Дождитесь публикации. Адрес будет похож на https://ИМЯ.github.io/profi-weather/
6. Откройте адрес на телефоне через мобильный интернет и проверьте, что прогноз загружается.
7. Только после публикации создайте QR-код, вставив постоянную ссылку на сайт в генератор QR.

Важные замечания:
- Координаты Быстринского ГОКа в index.html приблизительные (51.55, 118.60), не официальная метеостанция. Перед рабочим использованием уточните точку площадки.
- Координаты Газимурского Завода заданы ориентировочно.
- Open-Meteo предоставляет бесплатный доступ для некоммерческого использования при соблюдении его условий. Для корпоративного/коммерческого использования проверьте актуальную лицензию и тарифы.
- Прогноз модели может отличаться от фактической погоды на объекте. Не используйте сайт как единственный источник для допуска к опасным работам.
- Сайт обновляет данные при открытии, по кнопке и каждые 30 минут, если страница открыта.
